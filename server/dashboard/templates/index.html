Mitigationiptables / INPUT DROP
How it works: each ESP32 counts TCP packets, destination ports and login attempts in 3-second windows and publishes them over MQTT. The server extracts features, classifies them with the Decision Tree, and when a threat is detected with ≥ 85% confidence it adds an iptables DROP rule for the source IP on the server, removed automatically after 300 seconds. Every event is stored in SQLite and can be exported as CSV.
